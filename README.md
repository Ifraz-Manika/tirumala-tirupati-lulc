# LULC change, Tirumala and Tirupati (2000–2025)

Google Earth Engine (Python) notebook for the book chapter.

Run in Google Colab, top to bottom:
1. Put your own Earth Engine project id in the first code cell.
2. Run the cells in order. Sections 0–7 build the maps, accuracy and change tables.
   Section 7b runs the forest checks. Section 8 saves the Excel results
   (run it before Section 9, the figures).

Data (all public): Landsat Collection 2 Level 2, GHSL GHS-BUILT-S R2023A,
JRC Global Surface Water, Hansen Global Forest Change v1.13, ESA WorldCover.
Random seed 42.
